# Formik Education

Learning project: a register form with Formik, validated first with regex and then with Yup, with the field definitions and validation schema split into their own files.

پروژهٔ آموزشی Formik: فرم ثبت‌نام و اعتبارسنجی با Regex و Yup.

## Stack
React · Formik · Yup · Tailwind CSS

## Run
```bash
npm install
npm run dev
```
